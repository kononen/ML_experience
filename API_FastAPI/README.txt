	В данной папке написано АПИ для осуществления инференса моделей классификации, записи в базу данных PostgreSQL логов в таблицу logs и результатов инференса (метода или кодов ошибок) в таблицу tasks.

	1. Примечания: 

	1) Если в базе уже есть невыполненная (или «зависшая») задача, то мы возвращаем клиенту HTTP 503 Service Unavailable, потому что задача не может быть поставлена, пока предыдущая ещё не завершилась.

	2) Если при подключении к базе что-то пошло не так (например, не смогли соединиться), any_task_processing() тоже возвращает True (логгирует ошибку и «берёт безопасность»: чтобы не дать новый запрос, пока с БД проблемы).

	3) JSON-клиентам (через curl, Postman и т. п.) нужно отправлять «пустые» значения именно как null, а не как NaN !!!


	2. Возможные коды и описания ошибок у GET /status/{task_id} и GET /results/{task_id}

	1) /status: 200 (если всё ок), 400 (если пустой список), 404 (если хотя бы один task_id не найден), 500 (любой другой сбой).

	2) /results: 200 (даже если некоторые или все task_id не найдены, мы просто возвращаем "status":"not_found" в теле), 400 (если пустой список), 500 (при сбое БД/кода).
